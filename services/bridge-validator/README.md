# Burn service

`burn-service.mjs` provides the shared automatic cycle with private external configuration. Its direct development entrypoint accepts only localnet/devnet. `burn-mainnet-service.mjs` explicitly admits the Mainnet composition and enforces the protected Mainnet lifecycle and actual on-chain mode. The automatic serialized cycle observes, verifies, reserves, signs/broadcasts the exact Native burn, waits for finality, attests, claims, mints and reconciles. The protected journal and existing process lease survive restart. Public user endpoints are authenticated loopback; operator transitions are private local actions.

No public caller-supplied proof flag, signer replacement, arbitrary raw signing, administrative transition or reverse path exists. The public Mainnet Bridge remains activation pending and accepts no deposits. Read the root README and current readiness before running it. Never point this service at a retained reserve-model journal.

For Devnet, the private `solanaEndpoint` setting can contain the literal `ENV:SOLANA_DEVNET_RPC_URL`. The protected launcher supplies that process variable from its protected RPC store. The credential is never needed in the service configuration or command arguments. Missing or malformed values fail closed; actual Devnet genesis is still checked for every RPC operation. The reference cannot admit Mainnet or a local-validator endpoint.
