# Deposit reconciliation

Read-only Phase 08 reconciliation compares a revision-bound operation journal
with actual Native reserve validation and one finalized Solana bank snapshot.
Its Windows protected monitor retains progress and integrity incidents, reports
durable global stops, and never mints, signs, repairs balances or clears a stop.

See [scope and recovery limits](../../docs/security/deposit-reconciliation.md).
Complete unattended operation recovery remains a separate integration gate.
